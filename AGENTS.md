# dcd. portfolio

**dcd.** stands for Decide & Design, Code, Deploy. The site presents three software systems built by a team of four developers. Preserve the existing project facts and team records. Use actual assets or clearly illustrative artwork for new visual material.

- Use ASP.NET Core MVC controllers, typed C# models, and Razor partials for server-rendered content. See [README.md](README.md) for setup and paths.
- Keep browser behavior in the existing JavaScript modules. Use Tailwind utilities for common layout and CSS for the site's visual rules. Reuse GSAP, ScrollTrigger, and Lenis for motion.
- Follow [Blueprint Apps](https://blueprintapps.io/) for the loader, photo collage, and floating hero navigation. Follow [Pier Gorelli](https://piergorelli.com/) for editorial typography, the wireframe manifesto, scroll-pinned work, the progress ruler, and directional hover.
- Derive project counts, stages, and timeline distance from rendered data. Keep all projects readable on small screens, with reduced motion, and with JavaScript disabled.
- Keep visible focus, native dialog focus containment, keyboard shortcuts, and focus restoration. Check the responsive breakpoints and run the [verification checklist](docs/verification.md).
