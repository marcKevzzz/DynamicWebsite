# Contributing to dcd.

See [README.md](README.md) for setup, build and publish commands. Keep portfolio content in the C# models and use Razor partials for sections. Keep interaction state in the browser modules that own it. Preserve keyboard navigation, reduced motion, and the stacked project layout when changing scroll effects.

Run `dotnet build` and follow [the browser checks](docs/verification.md) before submitting a change.
